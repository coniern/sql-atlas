# 00 · 学习地图

> 这个知识库的所有 SQL 都跑在仓库自带的 `data/atlas.db`（一个 3000 单的真实感电商库）上。
> **文档里贴的每个查询结果，你都可以原样复现** —— 数据由固定种子生成，任何人跑出来都一模一样。

## 这张地图怎么用

```bash
git clone https://github.com/coniern/sql-atlas.git
cd sql-atlas
python src/seed.py        # 生成数据库（也可直接用仓库自带的）
python src/q.py           # 进入交互练习器
```

然后按下面的顺序读。每章 30~90 分钟，全读完大约 3 周。

## 学习方法（和上一个量化仓库同一套原则）

1. **每个查询都自己跑一遍** —— 读懂 ≠ 会写。`python src/q.py "SELECT ..."` 随手验证。
2. **改坏它** —— 把文档里的 SQL 改一个词，看报什么错、结果怎么变。错误信息是最好的老师。
3. **做完每章的自测题再走** —— 答不上来说明只是在"看小说"。
4. **用 DB Browser for SQLite**（sqlitebrowser）打开 `data/atlas.db` 点几下 —— 能看见数据长什么样，比脑补强十倍。

## 环境要求

- Python 3.10+（只用标准库 sqlite3，**不需要装任何包**）
- 可选：SQLAlchemy 2.x（只第 12 章用）、DB Browser for SQLite（可视化）
